# TSB-001 — Technical Security Baseline

**Status:** APPROVED  
**Approved:** 3 September 2026 (Neil)  
**In force for launch**

| Control | Value |
|---|---|
| Session absolute lifetime | 30 days |
| Mobile token lifetime | 30 days |
| Idle session timeout | **Not in v1** |
| Account deletion | Password confirmation |
| Password | Min 8; uppercase + number (existing signup rule retained) |
| Failed login | 8 attempts / 15 min, then 15 min friction; no permanent lockout |
| Signup | 5 / email / hour; 10 / IP / hour |
| Password reset | 5 / email / hour; link 60 min; 5 verification attempts |
| Chat | 20 / user / minute |
| Export | 5 / user / hour |
| Delete | 3 / user / hour |

Source of values in code: `lib/security-baseline.ts`.
