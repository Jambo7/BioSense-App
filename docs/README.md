# Client documents — drop zone

Drop the client's source documents into this `docs/` folder, then tell the
assistant **"docs are in"**.

## What to put here
- The client's briefs, methodology, content, tone/voice guides, feature specs,
  biomarker/scoring rules, clinical references — whatever he sent.

## Formats that can be read directly
- **PDF**, **Markdown (.md)**, **plain text (.txt)** — preferred.
- **Word (.docx)** can't be parsed cleanly — please export/save as PDF first,
  or paste the text in.

## Notes
- Keep the original filenames (they hint at each doc's purpose).
- No need to organise — just drop everything in; it'll be sorted and categorised.
